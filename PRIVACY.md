# Privacy Policy for InstaNeverPause

## Data Collection
InstaNeverPause does NOT collect any personal data or user information.

## Local Storage
The extension only stores your enable/disable preference locally on your device using Chrome's storage API.

## No Analytics
We do not use any analytics, tracking, or data collection services.

## No Network Requests
The extension does not make any network requests or communicate with external servers.
